#  Zomato Dataset Exploratory Data Analysis (EDA)

This project performs an exploratory data analysis (EDA) on the Zomato dataset to uncover key insights about restaurant trends, customer ratings, and geographic distributions of transactions. By analyzing numerical and categorical variables, the study identifies patterns and relationships that can help stakeholders in the food and hospitality industry make data-driven decisions.

## Key Questions Explored

 - Which countries have the highest number of Zomato transactions?
 - How are restaurants rated across different rating categories?
 - What is the distribution of restaurants with and without ratings?
 - Which cities have the highest number of transactions?
 - What are the most popular cuisines in the dataset?
 - Are there any missing values, and how do they impact the dataset?
 - What relationships exist between features such as location, ratings, and cuisine types?
